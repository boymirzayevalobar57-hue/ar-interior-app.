
# AR Interyer Dizayni

## Loyiha haqida
Ushbu loyiha kengaytirilgan reallik (AR) texnologiyasi yordamida mebel va interyer jihozlarini haqiqiy xona muhitida virtual joylashtirish uchun ishlab chiqiladi.

## Maqsad
A-Frame va WebXR texnologiyalari asosida interaktiv AR interyer dizayni ilovasini yaratish.

## Asosiy imkoniyatlar
- Real muhitda tekislikni aniqlash.
- 3D mebellarni joylashtirish.
- Mebellarni aylantirish.
- Obyekt o‘lchamini o‘zgartirish.
- Obyektlarni o‘chirish va sahnani tozalash.

## Texnologiyalar
- HTML
- CSS
- JavaScript
- A-Frame 1.5.0
- WebXR
- ARCore
- Git va GitHub
